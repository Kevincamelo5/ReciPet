## Si
Aplicación web creada como un recetario colaborativo entre los usuarios con el que se encuentran y suben diversas recetas referentes a bebidas, postres, platillos, botanas, entre otros.

## Funciones

1. Buscar recetas de interes.
2. Filtrar recetas con base a: ingredientes, utenciolios, tiempo de cocción y dificultad de preparación.
3. Calificar recetas vistas con base a puntajes de experiencia.
4. Guardar recetas de gusto popular para acceder a ellas de forma mas rapida.
5. Posicionar recetas en las paginas de resultados con base a las calificaciones, vistas y número de usuarios que tiene guardada la receta.
6. Publicar recetas con datos referentes a la información de preparación: ingredientes.
