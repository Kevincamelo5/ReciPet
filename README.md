# Reciper
Aplicacion web enfocada a la publicación y busqueda de distintas recetas filtrandose en el tiempo que lleva su elaboración, los ingredientes, el tipo de utencilio que requeridos por cada receta, la clasificacion de la receta y la dificultad para elaborar cada receta.
**Objetivo de la aplicación**
Para la subida de recetas el preservar recetas tradicionales en un repositorio en línea facil de usar accesible desde dispositivos moviles y ordenadores, y disponible las 24 hrs del día.

Para la consulta de recetas el entregar una fuente de busqueda de recetas distintas a los usuarios, las cuales puedan adaptarse a los elementos disponibles para si mismos tanto en ingredientes, como en utencilios, tiempo y habilidad requeridos para la elaboración de cada receta pudiendo personalizarse.

## Carcteristicas

+ Crear, buscar y guardar recetas en el servidor.
+ Aplicar, busquedas de recetas mediantes filtros aplicados a los tiempos, ingredientes, utencilios y la clasificación de cada receta.
+ Visualizar y calificar recetas de interes.
+ Copiar la lista de ingredientes en el portapapeles del dispositivo del usuarios.
+ Consultar, editar y eliminar recetas subidas con anterioridad.
